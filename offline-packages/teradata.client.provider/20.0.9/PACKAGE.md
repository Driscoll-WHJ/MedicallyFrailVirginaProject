## About

The .NET Data Provider for Teradata is an implementation of the Microsoft ADO.NET Data Provider specification. It provides direct access to the Teradata Database and integrates with the System.Data.DataSet class. .NET applications can use .NET Data Provider for Teradata to load data into and retrieve data from a Teradata Database.
